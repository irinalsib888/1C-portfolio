- **Системы контроля версий:** GitHub (этот репозиторий)
- **Дополнительно:** SQL (базовый), Excel, бизнес-анализ
- **Расширения для типовых конфигураций:** создание расширений для УТ

## 📂 Структура репозитория

### 1. `labs` – Базовые лабораторные работы  
Пошаговые задания из курса обучения. Отработаны:
- Создание справочников (в т.ч. иерархических, с реквизитами и табличными частями)
- Разработка документов с движениями по регистрам
- Настройка регистров накопления и регистров сведений
- Формирование отчётов с использованием СКД
- Механизмы «ввод на основании» и «заполнение объектов»

---
### 2. `radchenko_khrustaleva` – Примеры из учебника Радченко – Хрусталевой  
Самостоятельное изучение пособия *«1С:Предприятие 8. Примеры и типовые приёмы»*.  
Здесь представлены решения ключевых примеров: от простых справочников до сложных механизмов регистров и отчётов.  
Этот блок показывает, что я умею работать с фундаментальной литературой.

---
### 3. `tasks` – Решения простых ТЗ в УТ (без готовых шагов)  
В этой папке собраны **две простые задачи**, в которых требовалось доработать имеющуюся конфигурацию по техническому заданию (без пошагового руководства).  

---
### 4. `ut11_extension` – Расширения для типовой конфигурации «Управление торговлей»  
Здесь лежат **самостоятельные задачи** по созданию расширения для УТ.  
Расширение позволяет доработать типовую конфигурацию без изменения её ядра – что является стандартной практикой в промышленной разработке.

Этот опыт показал, как:
- Работать с механизмом расширений
- Находить нужные объекты в типовой УТ
- Вносить изменения, не затрагивая основной код

*Примечание:* все работы выполнены в учебных целях и могут содержать упрощения.

# Расширение для документа «Приобретение товаров и услуг» (УТ 11.5)

## Описание
В рамках самостоятельной учебной практики создано расширение для конфигурации «Управление торговлей» редакции 11.5.

**Доработка документа «Приобретение товаров и услуг»:**

1. **Поле «НДС»** – стало редактируемым (снята галочка «Только просмотр»).
2. **Кнопка «Отменить проведение»** – добавлена в командную панель документа (стандартная команда).
3. **Кнопка «Очистить товары»** – добавлена в группу «Товары»; при нажатии очищается табличная часть документа.

## Используемые механизмы
- Механизм расширений конфигурации (файл `.cfe`).
- Изменение формы документа (свойства полей, командная панель).
- Добавление собственной команды на форму.

## Как проверить
1. Установите расширение в базу УТ 11.5 (загрузите файл `.cfe` через Конфигуратор → Расширения → Загрузить).
2. Откройте документ «Приобретение товаров и услуг».
3. Убедитесь, что поле НДС редактируется, кнопки присутствуют и работают.

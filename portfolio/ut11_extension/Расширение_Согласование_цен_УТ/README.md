# Расширение "Согласование цен" для 1С:Управление торговлей 11.5

## 📌 Цель работы
Разработать расширение для типовой конфигурации 1С:УТ 11.5, которое автоматизирует процесс согласования нестандартных цен в документах «Заказ клиента». Расширение выполнено без снятия конфигурации с поддержки.

## 🛠 Исходные данные
- **Платформа:** 1С:Предприятие 8.3 (не ниже 8.3.24)
- **Конфигурация:** Демо «Управление торговлей» редакция 11.5 (11.5.11.70)

## 📋 Функциональные требования

### 1. Добавленные реквизиты в документ «Заказ клиента»
| Реквизит | Тип | Назначение |
|----------|-----|------------|
| `ТребуетсяСогласованиеЦены` | Булево | Признак необходимости согласования цены |
| `Согласована` | Булево | Статус согласования |
| `КомментарийСогласования` | Строка (200) | Причина отклонения |

### 2. Модификация формы документа
- Созданные реквизиты выведены в отдельную группу на форме.
- Добавлена командная панель с кнопками:
  - **«Согласовать»** – доступна, когда `ТребуетсяСогласованиеЦены = Истина` и `Согласована = Ложь`.
  - **«Отклонить»** – доступна при тех же условиях.

### 3. Бизнес-логика (автоматическое определение)
При записи документа (перед записью) проверяются все строки табличной части «Товары»:
- Если скидка (в процентах или сумме) в любой строке превышает **10%** от базовой цены номенклатуры → `ТребуетсяСогласованиеЦены = Истина`.
- В противном случае → `Ложь`.

### 4. Обработчики кнопок
- **«Согласовать»** → устанавливает `Согласована = Истина` и записывает документ.
- **«Отклонить»** → открывает диалог для ввода комментария и устанавливает `Согласована = Ложь`.

## ⚙️ Технические требования
- Тип расширения: **«Адаптация»**.
- Весь код размещён во внешнем расширении (файл `.cfe`).
- **Запрещено** изменение модулей типовой конфигурации напрямую.
